Primal Armor is an independently developed control tool for user-installed visual mods.
No game assets, The Primal/DiLied assets, Dalamud binaries, Penumbra binaries or
Glamourer binaries are included or relicensed. Recipe metadata identifies compatible
options and game resource paths; it does not contain mod asset data.

Dalamud: https://github.com/goatcorp/Dalamud
Penumbra: https://github.com/xivdev/Penumbra
Glamourer: https://github.com/Ottermandias/Glamourer

The application uses the runtime IPC interfaces supplied by the user's installed
plugins. No affiliation or endorsement by those authors is implied.
