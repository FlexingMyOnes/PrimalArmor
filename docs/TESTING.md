# 實機與多人測試

本文件列出尚需在遊戲內確認的項目，不能以離線測試取代。

## 首次載入

- 停止舊 SND 巨集，並取消其 OnLogin；載入 DLL 不出現例外。
- `/primalarmor` 能開啟介面，預設停用，偵測結果符合自己安裝的模組。
- 不需要原開發者的磁碟路徑或集合 ID，也沒有要求未購買的模組。

## 畫面

- 同畫面至少兩個不同 Primal 職業各自顯示自己的效果。
- 不同種族／性別的效果位置正確。相同選項的種族共用集合。
- 首次出現的暗騎、吟遊、生產／採集職業不出現占星或其他 Primal 盔甲效果。
- Primal → 非 Primal、非 Primal → Primal、Primal → 另一 Primal 切換正確。
- 原技能效果、自己的外觀、NPC 與其他裝備設定符合預期。

## 範圍與效能

- 隊友限定、距離、人數上限及停用單一職業生效。
- 同一批未變更玩家不反覆重載；換區、移動及新玩家出現時分批套用。
- 在海都大水晶，以相同位置／視角比較啟用與停用時的表現。記錄硬體、FPS、是否大量載入模組，不以單次觀感當效能結論。
- 介面診斷的累計完整重載數量符合操作，不持續無故增加。

## 清理與失敗

- 停止、停用、登出、換角色、卸載後暫存效果被移除。
- 玩家離開後另一人使用同物件索引，不還原錯誤帽子。
- 與同步工具共用時，無法完整讀取的集合能清楚提示並略過。
- 缺少／更新／卸載 Penumbra 或 Glamourer 時，停止套用並顯示訊息。
- 故意缺少某個 Primal 資源後重新偵測，只略過不相容選項。
- 清理失敗能在本機日誌看見，插件仍載入時保留紀錄重試；重新登入可重設暫存狀態。

回報時提供遊戲與三個插件版本、哪個職業／種族、啟用的範圍設定、診斷訊息與畫面。貼出日誌前自行移除不想公開的角色名稱與本機路徑。
