# Primal Armor — 公開測試版 0.1.0.1

在自己的畫面中，依其他玩家的職業與種族／性別，自動選擇已安裝的 The Primal 盔甲特效。

`0.1.0.1` 修正 `Value cannot be null. (Parameter 'path1')` 導致一直「掃描失敗」的問題：模組對照表已內建於 DLL，支援插件從記憶體載入。已安裝者從插件安裝器更新，再按「重新偵測模組並重建設定」即可；自訂插件庫網址不變。

新增「Penumbra 模組根目錄（選填）」欄位：留空會讀取 Penumbra 設定，也可貼上自己的模組總資料夾完整路徑，再按「重新偵測模組並重建設定」。請選擇包含各模組子資料夾的總目錄。按「恢復自動偵測」可清空指定路徑並重新掃描；實際掃描位置會顯示在介面。

目標環境是 **FFXIV 台服 7.25、Dalamud API 13、Windows / .NET 9**。目前以台服 Penumbra 1.5.1.26、Glamourer 1.5.0.13 的介面驗證。這是第一版獨立插件，已通過編譯與離線回歸檢查，仍需實機及多人測試。

## 包含什麼

- 自動從 Penumbra 設定尋找模組資料夾及原集合；沒有寫死使用者名稱、磁碟代號或收藏集 ID。
- 自動尋找 MNK、DRG、BLM、AST、RDM、RPR、SGE、VPR 八種 Primal 封包，共 144 種種族／性別選擇。
- 未安裝的職業或不相容選項會略過並顯示診斷，不需要湊齊所有模組。
- 非對應職業清除共用設定誤套的 Primal 盔甲效果，保留技能特效與原帽子。
- 距離、隊友限定、特效人數上限、處理間隔及登入自動啟動設定。
- 每次只處理一位變更玩家；相同選項共用暫存集合，分幀讀取原技能資源。
- 停止、換角色、登出時清理暫存設定；不改寫原模組、Glamourer 設計或 C+ 範本。
- 正常刷新不在聊天室逐次通知；狀態與問題集中在設定介面及本機日誌。

本包只包含工具程式和選項對應資料。**沒有 Primal、其他付費模組、Dalamud、Penumbra 或 Glamourer 的資源／程式檔案**，使用者需自行安裝相關插件及原作者模組。SND 不是獨立插件版的依賴。

## 安裝公開測試版

1. 如果使用過舊 SND 版，先停止 `Primal Armor Auto`，並取消那個巨集的 `OnLogin`。不要同時啟用兩個版本。
2. 遊戲內開 Dalamud 設定 →「實驗性 / Experimental」→「自訂插件庫 / Custom Plugin Repositories」，加入以下網址並儲存：

   ```text
   https://raw.githubusercontent.com/FlexingMyOnes/PrimalArmor/main/repo.json
   ```

3. 在插件安裝器搜尋並安裝 **Primal Armor**。這是尚待實機驗證的公開測試版。
4. 輸入 `/primalarmor`，確認有偵測到自己的模組，再勾選「啟用盔甲特效」。
5. 想在登入時自動執行，保持「啟用」，並勾選「登入後自動啟動」。更新會透過同一個自訂插件庫提供。

若台服啟動器無法讀取 GitHub 插件庫，可從 [Releases](https://github.com/FlexingMyOnes/PrimalArmor/releases) 下載測試包，依下方方式載入。

## 手動測試安裝

1. 如果使用過舊 SND 版，先停止 `Primal Armor Auto`，並取消那個巨集的 `OnLogin`。不要同時啟用兩個版本。
2. 解壓縮發布包，將 `PrimalArmor.dll`、`PrimalArmor.json`、`assets` 資料夾放在一起，放在日後不會移動的位置。
3. 遊戲內開 Dalamud 設定 →「實驗性 / Experimental」→「開發插件位置 / Dev Plugin Locations」。加入 `PrimalArmor.dll` 的完整路徑，然後載入插件。可參考 [Dalamud 的開發插件說明](https://dalamud.dev/faq/getting-started/)。
4. 輸入 `/primalarmor`，查看八個職業是否有偵測到你自己的模組。
5. 勾選「啟用盔甲特效」。首次預設為停用；啟用後先等人物與依賴就緒，再分批套用。
6. 如果偵測失敗，先看「診斷資訊」。重新安裝、改名、更新或調整 Penumbra 設定後，按「重新偵測模組並重建設定」。

一般使用者不需要安裝 .NET SDK、不需要編譯、不需要貼 Lua 巨集。

## 指令與設定

| 操作 | 指令／設定 |
|---|---|
| 開啟介面 | `/primalarmor` |
| 本次啟用 | `/primalarmor on` |
| 停止並還原 | `/primalarmor off` |
| 下次登入自動開始 | 保持「啟用」，並勾選「登入後自動啟動」 |
| 人多時減輕負擔 | 降低特效距離／人數，或增加每位玩家處理間隔 |

預設套用距離 40、最多 40 位、每位間隔 150 毫秒。限制影響的是新增的盔甲效果；其他玩家仍會移除共用設定誤套的 Primal 盔甲效果。大量玩家首次出現時，效果會逐漸出現。模型與特效本身仍有載入／繪製負擔。

不處理自己的角色、NPC、召喚物或 GPose 分身。原帽子會被皇帝帽取代，作為受支援職業的特效載體。同步插件或其他工具建立的暫存集合若無法完整讀取，會略過該玩家。
